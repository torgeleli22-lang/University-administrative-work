# 출석인정허가원 자동생성

학생 정보/수강 시간표를 DB에서 불러와 신구대학교 출석인정허가원(.hwpx) 서식에
자동으로 채워 넣고 다운로드하는 웹앱입니다. 원본 한글 서식의 디자인/서식은
전혀 건드리지 않고, 표 안의 빈 칸에 내용만 채워 넣습니다.

## 실행 방법 (로컬)

```bash
pip install -r requirements.txt
python -m app.seed          # 데모용 소량 샘플 데이터 (실제 데이터는 아래 참고)
python -m flask --app app.app run
```

브라우저에서 http://127.0.0.1:5000 접속 → 학생 검색/선택 → 결석 사유·기간·과목
선택 → "한글(.hwpx) 파일로 다운로드" 클릭. 상단의 "사용 기록" 링크에서 지금까지
생성된 허가원 이력을 확인할 수 있습니다.

## 실제 학사 데이터 넣기

`python -m app.import_real_data`로 학교에서 내려받은 원본 .xls 파일 3종을 그대로
가져올 수 있습니다.

```bash
python -m app.import_real_data \
  --roster 재학생명단.xls \
  --timetable 1:1학년시간표.xls \
  --timetable 2:2학년시간표.xls \
  --timetable 3:3학년시간표.xls \
  --timetable 4:4학년시간표.xls \
  --syllabus 강의계획서.xls
```

- **재학생명단** (`--roster`, 1개): 학과/학년/반별로 묶여 있는 전체 재학생 명단.
  학번/이름/학과/학년/반만 저장하고, 파일에 있는 주민등록번호는 서식에 필요
  없는 정보라 아예 저장하지 않습니다.
- **학과별 전체시간표** (`--timetable 학년:경로`, 학년별로 1개씩): 요일×교시
  표에서 "분반 과목명 교수명 건물 강의실" 형태의 셀을 파싱해서 과목명/담당교수/
  수업일/수업시간을 만듭니다. 결석 과목 선택 목록과 서식에 들어가는 내용이 전부
  이 파일에서 나옵니다.
- **강의계획서 입력 현황** (`--syllabus`, 선택): 과목 코드/학점을 보강하는
  용도이고, 여기에만 있고 시간표에는 없는 과목(아직 강의실 미배정 등)은
  수업일/수업시간을 "미정"으로 채워 넣습니다.

매 학기 다시 받은 파일로 같은 명령을 실행하면 됩니다. `--term`을 생략하면
`app/config.py`의 `TERM` 값(현재 `"2026-2"`)을 쓰므로, 학기가 바뀌면 그 값도
같이 바꿔주세요.

### ⚠️ 개인정보 취급 주의

재학생명단·강의계획서·시간표 원본 파일과, 그 파일로 채워진 `data/attendance.db`는
**절대 git에 커밋하지 마세요** (`.gitignore`에 이미 제외 처리는 되어 있습니다).
실제 이름·학번이 들어간 데이터베이스는 배포 서버에만 두고, 로컬에서는 파일을
받아서 가져오기(import)만 하고 지우는 방식을 권장합니다.

## 과목당 사용 횟수 제한 + 사용 기록

"한 과목 및 수업당 출석인정허가원 2회 이상 사용 불가" 규정에 따라
`app/config.py`의 `MAX_USES_PER_COURSE = 1`로 과목당 학기 중 1회까지만 허용하고
있습니다 (규정이 다르게 해석되면 이 값만 바꾸면 됩니다). 허가원을 생성할 때마다
`permit_records` 테이블에 학생/과목/사유/기간을 기록하고, 이미 한도를 채운
과목은 선택 화면에서 비활성화되며 서버에서도 다시 한번 막습니다. `/records`
페이지에서 전체 이력을 볼 수 있습니다 (지금은 별도 로그인 없이 열려 있으니,
외부에 공개하기 전에 관리자 인증을 추가하는 걸 권장합니다 — 아래 "남은 일" 참고).

## 웹에 배포하기 (무료 도메인/호스팅)

Flask 앱을 `gunicorn`으로 띄우도록 `Procfile`을 준비해뒀습니다
(`web: gunicorn 'app.app:app'`). Render, Railway, Fly.io 같은 곳은 무료 요금제로
`프로젝트이름.onrender.com` 같은 무료 서브도메인을 바로 내어줍니다 — 이 앱을
그대로 올리면 도메인 구매 없이도 인터넷에서 접속 가능한 주소가 생깁니다.

다만 "완전 무료" 정식 도메인(.com/.kr 등)은 실질적으로 없다는 점은 미리
알아두시면 좋습니다. 예전에 흔했던 Freenom(.tk/.ml 등) 무료 도메인은 더 이상
신규 발급을 하지 않고, `eu.org`처럼 심사 후 받을 수 있는 무료 도메인도 있지만
느리고 제한적입니다. 실용적인 선택지는 두 가지입니다.

1. 호스팅사에서 주는 무료 서브도메인 그대로 사용 (완전 무료, 가장 간단)
2. 짧고 기억하기 쉬운 진짜 도메인이 필요하면 `.com` 기준 1년에 보통
   1만원 내외로 구매 (Namecheap, 가비아 등)

호스팅 계정 생성이나 도메인 결제는 제가 대신 할 수 없는 부분이라
(결제수단/계정 소유권 문제), 계정만 만들어주시면 배포 설정 파일 정리나 연결은
같이 진행할 수 있습니다.

## 구조

- `app/config.py` — 학기(`TERM`), 요일 순서, 과목당 사용 제한 상수
- `app/db.py` — SQLite 스키마 (students, courses, course_slots, permit_records)
- `app/import_real_data.py` — 재학생명단/시간표/강의계획서 .xls → DB 적재
- `app/seed.py` — 소량 데모 데이터 (실 데이터 없이 빠르게 돌려볼 때)
- `app/queries.py` — 학생별 수강 과목 + 사용 횟수 조회 헬퍼
- `app/hwpx_filler.py` — hwpx 템플릿을 열어 표 셀에 값을 채우고 다시 압축하는 핵심 로직
- `app/app.py` — Flask 라우트 (학생 목록/검색, 작성 폼, 생성+다운로드, 사용 기록)
- `app/templates/`, `app/static/` — 화면
- `app/assets/attendance_permit_template.hwpx` — 학교 원본 서식 (수정 금지)
- `docs/hwpx-field-map.md` — hwpx 표 좌표와 필드 매핑 문서 (서식이 바뀌면 참고)

## 알아둘 점 / 남은 일

- 결석 과목은 서식에 있는 빈 줄 수만큼(현재 7개)까지만 채울 수 있습니다.
- 지도교수/학과장 결재란은 실제 서명/날인용이라 자동으로 채우지 않습니다.
- 신청일자는 항상 오늘 날짜로 채워집니다.
- `/records` 페이지는 현재 누구나 볼 수 있습니다. 실제 서비스로 올리기 전에
  관리자 로그인(또는 최소한 접근 비밀번호)을 붙이는 걸 권장합니다.
