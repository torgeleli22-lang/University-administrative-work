# 출석인정허가원 hwpx 필드 맵

`app/assets/attendance_permit_template.hwpx`는 학교에서 내려받은 원본 서식이며
디자인/서식은 절대 건드리지 않는다. `app/hwpx_filler.py`는 이 파일을 zip으로 열어
`Contents/section0.xml`의 표 셀(`hp:tc`)을 좌표(`rowAddr`, `colAddr`)로 찾아 텍스트만
채워 넣는다.

셀 좌표는 `lxml`로 원본 XML을 파싱해서 직접 확인한 값이다(표가 바뀌면 다시 확인해야
한다):

## 표 구조 (`Contents/section0.xml` 안의 `hp:tbl`)

- **결재 표** (`rowCnt=2`): 지도교수/학과장 서명란. 자동 입력 대상 아님 (실제 결재).
- **메인 표** (`rowCnt=14`, `colCnt=10`): 학생 정보, 결석 사유, 결석 기간, 결석 과목,
  제출 문구가 모두 이 표 안에 있다.
  - `(1,0)` 학과명 / `(1,2)` 학년 / `(1,3)` 학번 / `(1,6)` 반 / `(1,8)` 성명
  - `(3,1)` 결석 기간 문자열 전체 (한 줄로 조립해서 통째로 교체)
  - `(4..11, 1/4/5/7)` 결석 과목 표: 행 5~11 (7행) × 과목명/담당교수/수업일/수업시간
  - `(12,0)` 안에 자유 텍스트 런이 여러 개 들어있는데, 그중
    `"2026년    월    일"`과 `"신  청  자:             (인)"`는 문서 전체에서
    유일한 문자열이라 텍스트 매칭으로 교체한다.
- **결석사유 체크박스 표** (`rowCnt=6`, `colCnt=7`): 메인 표의 `(2,1)` 셀 안에
  중첩된 표. 각 사유 번호(1~9)에 대응하는 `□` 셀 좌표는
  `hwpx_filler.REASON_CHECKBOX_CELLS`에 정의되어 있다. 선택된 사유의 `□`를
  `■`로 바꿔서 "체크"를 표현한다.

## 셀에 텍스트를 넣는 방법

hwpx 표 셀은 `hp:tc > hp:subList > hp:p > hp:run > hp:t` 구조다. 빈 칸은 보통
`<hp:run charPrIDRef="..."/>`처럼 `hp:t`가 아예 없는 self-closing run이고,
체크박스처럼 이미 글자가 있는 칸은 컨트롤 전용 run(`<hp:ctrl>`, 텍스트 없음) +
실제 텍스트 run 두 개로 이루어져 있다. `_set_cell_text()`는 먼저 기존
`hp:t`를 찾아 값을 바꾸고, 없으면 `hp:ctrl`이 없는 run에 새 `hp:t`를 만들어
넣는다.

표 밖 다른 파일(`header.xml`, `settings.xml`, `content.hpf`, 미리보기 이미지 등)은
전혀 건드리지 않고 원본 압축 방식 그대로 다시 담아서 zip을 만든다.
